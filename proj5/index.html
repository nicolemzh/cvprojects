Project 5: Diffusion Models

Exploring the Power of diffusion models for image generation, manipulation, and creative applications!

Overview

This project explores diffusion models, one of the most powerful techniques in modern generative AI. In Part A, I work with pre-trained diffusion models (DeepFloyd IF) to explore various denoising techniques, and create optical illusions. In Part B, I build and train my own flow matching model from scratch on the MNIST dataset, implementing a UNet architecture and training pipeline to generate handwritten digits.

Part 1: Sampling Loops

Part 1.1: Implementing the Forward Process

The forward process adds noise to a clean image. I implemented the forward function using the formula:

x_t = √(ᾱ_t) * x_0 + √(1 - ᾱ_t) * eps

where eps ~ N(0, I) is random Gaussian noise according to instructions.

Part 1.6: Classifier-Free Guidance (CFG)

I implement Classifier-Free Guidance which dramatically improves image quality because it combines both conditional and unconditional noise estimates. The formula I use is: eps = eps_u + γ(eps_c - eps_u), where γ controls the guidance strength. I used γ = 7 for these results which created good results.

Part 1.8: Visual Anagrams

Visual anagrams are optical illusions where an image appears as one thing normally, but reveals a different image when flipped upside down. I achieved this by averaging noise estimates from the original and flipped images during each denoising step. I first denoise the original image, then flip it upside down to denoise the second image. I flip it back around then average the noise estimates to compute one denoising step.

Part 1.9: Hybrid Images

Following the Factorized Diffusion approach, I created hybrid images by combining low frequencies from one noise estimate with high frequencies from another. When viewed up close, you see one image from the high-pass frequencies; from far away, you see the other from the low-pass frequencies. At each denoising step, I get the noise estimate for prompt 1 and 2. I apply the low-pass filter to eps_1 using a gaussian blur. I then apply a high-pass filter to eps_2 which is just the original - low-pass. I combine these frequencies to compute a single step.

Part B: Flow Matching from Scratch

Part 1.1: Implementing the UNet

I implemented a UNet architecture for denoising MNIST digits. The UNet consists of downsampling blocks (encoder), flattening + unflattening (bottleneck), and upsampling blocks (decoder) with skip connections to preserve spatial information.

I trained the UNet for 5 epochs on MNIST with σ = 0.5, using Adam optimizer (lr=1e-4) and batch size 256. The model learns to denoise images effectively, as shown by the loss curve.

I tested the denoiser on noise levels it wasn't trained on (σ = [0.0, 0.2, 0.4, 0.5, 0.6, 0.8, 1.0]). The model performs best at σ = 0.5, which makes sense, and degrades gracefully for other noise levels.

Part 2: Training a Flow Matching Model

Part 2.1: Adding Time Conditioning to UNet

For flow matching, I designed a UNet that predicts the flow from noisy data to clean data x. The important idea is conditioning the UNet on time t, which tells the model how noisy the current image is.

Time-conditioned UNet Architecture

FCBlock Architecture

Part 2.2: Training the Time-Conditioned UNet

I trained the time-conditioned UNet using flow matching objective. For each training step, I sample a random timestep t, create noisy image x_t = t·x_1 + (1-t)·x_0, and supervised the network to predict the target flow vector.

Training Configuration

  • Batch size: 128
  • Hidden dimension (D): 128
  • Optimizer: Adam with lr=1e-3
  • Num of epochs: 10
  • Num ts: 50
  • Learning rate scheduler: ExponentialLR
