Project 3: Image Warping, Mosaicing, and Feature Matching for Autostitching

Creating panoramic mosaics through homography computation, image warping, and automatic feature detection

Overview

This project explores the mathematics and implementation of image mosaicing - the process of stitching multiple photographs into seamless panoramas. I implemented homography computation from scratch, developed two interpolation methods for image warping (nearest neighbor and bilinear), and created distance-weighted blending for smooth transitions. I then extended this to automatic feature detection using the Harris corner detector, adaptive non-maximal suppression (ANMS), and Lowe's algorithm for matching points across images. Finally, I implemented RANSAC to robustly estimate homographies from noisy correspondences. The techniques learned enable the creation of wide-angle panoramas from overlapping photographs and rectification of perspective distortions.

Part A.2: Recover Homographies

A homography H is a 3×3 matrix that maps points from one image to another: p' = Hp. I used 10-15 correspondences to create an overdetermined system and solve using least-squares.

Mathematical Formulation

I create a linear system Ah = b where:

• A is 2n × 8 (n point correspondences)

• h = [h₁, h₂, h₃, h₄, h₅, h₆, h₇, h₈]ᵀ

• b alternates x' and y' coordinates: [x₁', y₁', x₂', y₂', ...]

Implementation

def computeH(im1_pts, im2_pts):
        '''
        im1_pts, im2_pts are nx2 matrices
        '''
        n = im1_pts.shape[0]
        
        A = []
        for i in range(n):
        x1, y1 = im1_pts[i]
        x2, y2 = im2_pts[i]
        A.append([x1, y1, 1, 0, 0, 0, -x1*x2, -y1*x2])
        A.append([0, 0, 0, x1, y1, 1, -x1*y2, -y1*y2])
        
        A = np.array(A)
        
        b = np.empty(2*n, dtype=np.float64)
        b[0::2] = im2_pts[:, 0] # x'
        b[1::2] = im2_pts[:, 1] # y'
        
        h, residuals, rank, s = np.linalg.lstsq(A, b, rcond=None)
        H = np.vstack([h.reshape(8, 1), 1]).reshape(3, 3)
        
        return A, b, H, h

Part A.3: Warp the Images

I implemented inverse warping to avoid holes in the output. For each output pixel, I compute its source location using H⁻¹, then interpolate the pixel value. Two interpolation methods were implemented from scratch:

Nearest Neighbor

    Nearest neighbor interpolation works by rounding the source coordinates to the nearest integer pixel location. It then copies the exact pixel value from this closest position to the output image. This method is very fast and simple to implement, making it efficient for real-time applications. However, it produces visible aliasing effects because it does not perform any smoothing or blending of pixel values.

Bilinear Interpolation

    Bilinear interpolation calculates the output pixel value as a weighted average of the four nearest pixels surrounding the mapped source coordinate. The weights depend on the fractional distance between the source coordinate and these neighboring pixels, allowing smooth transitions. This ends up producing smoother, anti-aliased images, resulting in better visual quality. However, the computation involves indexing multiple pixels and computing a weighted sum per output pixel, making it approximately four times slower than nearest neighbor interpolation. Additionally, results may appear slightly blurred due to smoothing as shown in the garden path and haas images.

Inverse Warping Implementation


    def warpImageNearestNeighbor(im, H):
        h, w = im.shape[:2]
        color = len(im.shape) == 3
        
        x_min, x_max, y_min, y_max = computeBounds(im, H)
        
        # output dimensions
        out_w = int(np.ceil(x_max - x_min))
        out_h = int(np.ceil(y_max - y_min))
        
        if color:
            warped = np.zeros((out_h, out_w, im.shape[2]), dtype=im.dtype)
        else:
            warped = np.zeros((out_h, out_w), dtype=im.dtype)
        
        alpha = np.zeros((out_h, out_w), dtype=np.float32)
        
        H_inv = np.linalg.inv(H)
        
        # offset
        x_out, y_out = np.meshgrid(np.arange(out_w), np.arange(out_h))
        x_out_shifted = x_out + x_min
        y_out_shifted = y_out + y_min
        
        ones = np.ones_like(x_out_shifted)
        coords_out = np.stack([x_out_shifted, y_out_shifted, ones], axis=0) # 3 x out_h x out_w

        # flatten
        coords_out = coords_out.reshape(3, -1) # 3 x (out_h * out_w)
        
        coords_in = H_inv @ coords_out # 3 x (out_h * out_w)
        coords_in = coords_in / coords_in[2, :]
        
        x_in = coords_in[0, :].reshape(out_h, out_w)
        y_in = coords_in[1, :].reshape(out_h, out_w)
        
        # compute NN
        x_in_nn = np.round(x_in).astype(int)
        y_in_nn = np.round(y_in).astype(int)
        
        valid = (x_in_nn >= 0) & (x_in_nn < w) & (y_in_nn >= 0) & (y_in_nn < h)
        
        if color:
            for c in range(im.shape[2]):
                warped[:, :, c][valid] = im[y_in_nn[valid], x_in_nn[valid], c]
        else:
            warped[valid] = im[y_in_nn[valid], x_in_nn[valid]]
        
        alpha[valid] = 1.0 # 1 if pixel is non-zero, else 0
        
        offset = (x_min, y_min)
        return warped, alpha, offset

    def warpImageBilinear(im, H):
        h, w = im.shape[:2]
        color = len(im.shape) == 3
        
        x_min, x_max, y_min, y_max = computeBounds(im, H)
        
        # output dimensions
        out_w = int(np.ceil(x_max - x_min))
        out_h = int(np.ceil(y_max - y_min))
        
        if color:
            warped = np.zeros((out_h, out_w, im.shape[2]), dtype=im.dtype)
        else:
            warped = np.zeros((out_h, out_w), dtype=im.dtype)
        
        alpha = np.zeros((out_h, out_w), dtype=im.dtype)
        
        H_inv = np.linalg.inv(H)
        
        # offset
        x_out, y_out = np.meshgrid(np.arange(out_w), np.arange(out_h))
        x_out_shifted = x_out + x_min
        y_out_shifted = y_out + y_min
        
        ones = np.ones_like(x_out_shifted)
        coords_out = np.stack([x_out_shifted, y_out_shifted, ones], axis=0) # 3 x out_h x out_w

        # flatten
        coords_out = coords_out.reshape(3, -1) # 3 x (out_h * out_w)
        
        coords_in = H_inv @ coords_out # 3 x (out_h * out_w)
        coords_in = coords_in / coords_in[2, :]
        
        x_in = coords_in[0, :].reshape(out_h, out_w)
        y_in = coords_in[1, :].reshape(out_h, out_w)
        
        # bilinear interpolation
        x_floor = np.floor(x_in).astype(int)
        y_floor = np.floor(y_in).astype(int)
        x_ceil = x_floor + 1
        y_ceil = y_floor + 1
        
        dx = x_in - x_floor
        dy = y_in - y_floor
        valid = (x_floor >= 0) & (x_ceil < w) & (y_floor >= 0) & (y_ceil < h)
        
        # calculate weights based on distance
        w_tl = (1 - dx) * (1 - dy)
        w_tr = dx * (1 - dy)
        w_bl = (1 - dx) * dy
        w_br = dx * dy
        
        if color:
            for c in range(im.shape[2]):
                warped[:, :, c][valid] = (
                    w_tl[valid] * im[y_floor[valid], x_floor[valid], c] +
                    w_tr[valid] * im[y_floor[valid], x_ceil[valid], c] +
                    w_bl[valid] * im[y_ceil[valid], x_floor[valid], c] +
                    w_br[valid] * im[y_ceil[valid], x_ceil[valid], c]
                )
        else:
            warped[valid] = (
                w_tl[valid] * im[y_floor[valid], x_floor[valid]] +
                w_tr[valid] * im[y_floor[valid], x_ceil[valid]] +
                w_bl[valid] * im[y_ceil[valid], x_floor[valid]] +
                w_br[valid] * im[y_ceil[valid], x_ceil[valid]]
            )
        
        alpha[valid] = 1.0 # 1 if pixel is non-zero, else 0
        
        if im.dtype == np.uint8:
            warped = np.clip(warped, 0, 255).astype(np.uint8)
        
        offset = (x_min, y_min)
        return warped, alpha, offset

Part A.4: Blend Images into a Mosaic

I implemented distance-weighted blending using bilinear interpolation warping where each image's contribution is based on distance from its edges. This is recorded in the alpha mask, where pixels at the center of an image get full weight (1.0), while edges get progressively less weight, creating smooth transitions in overlap regions.

Blending Algorithm

1. Create alpha masks: Mark valid pixels (1.0) vs empty regions (0.0)

2. Distance transform: Compute distance from each pixel to nearest zero- pixel (0.0)

3. Normalize weights: Scale distances to [0, 1] range

4. Weighted blend: Blended = (im1 × w1 + im2 × w2) / (w1 + w2)

This ensures w1 + w2 = 1 everywhere, preventing brightness artifacts while smoothly transitioning between images.

Blending Analysis

Using this blending algorithm, pixels far from image edges usually come from only one source image, so they receive full weight from that image. Near edges, where small alignment errors or differences may occur, blending both images gradually helps to mask these imperfections. This smooth transition of weights effectively prevents visible seams between images. However, change in position, time, lighting, and parallax can still cause noticeable differences.

Part B: Automatic Feature Detection & Matching

Part B implements automatic feature detection and matching based on the MOPS (Multi-Scale Oriented Patches) paper by Brown et al., making the mosaicing pipeline fully automatic and scalable.

Part B.1: Harris Corner Detection & ANMS

Harris Corner Detection

I used the Harris Interest Point Detector (Section 2 of MOPS) to find distinctive corners in each image. Harris corners are points where intensity changes significantly in all directions.

Adaptive Non-Maximal Suppression (ANMS)

ANMS (Section 3 of MOPS) selects a spatially distributed subset of the strongest corners. For each corner, I compute its "suppression radius" - the minimum distance to a significantly stronger corner. Corners with larger suppression radii are more spatially isolated and thus are chosen for matching.

ANMS Algorithm

1. Sort corners by strength (descending order)

2. For each corner i:

• Find minimum distance to any corner j where strength(j) > c_robust × strength(i)

• c_robust = 0.9 ensures we only consider significantly stronger corners as used in the paper

3. Select top N corners with largest suppression radii

Part B.2: Feature Descriptor Extraction

For each detected corner, I extract an 8×8 feature descriptor (Section 4 of MOPS). The key insight is to sample from a larger 40×40 window at 5-pixel intervals, which provides robustness to small localization errors while capturing the essential local structure. Each descriptor is then bias/gain normalized (zero mean, unit variance) to achieve invariance to affine intensity changes.

Descriptor Extraction Algorithm

1. Extract 40×40 window: Centered at each feature point

2. Sample at 5-pixel spacing (used in the paper): Create 8×8 grid by sampling every 5th pixel

• Positions: [0, 5, 10, 15, 20, 25, 30, 35] in both x and y

• This gives (8-1) × 5 = 35 pixels from center to edge

3. Flatten to 64-dimensional descriptor vector

4. Normalize: desc_norm = (desc - mean(desc)) / std(desc)

Part B.3: Feature Matching

To find correspondences between images, I match descriptors using Lowe's ratio test (Section 5 of MOPS).

Lowe's Ratio Test Algorithm

For each descriptor d₁ in image 1:

1. Compute L2 distance to all descriptors in image 2: dist_i = ||d₁ - d₂_i||₂

2. Find two nearest neighbors: d₂_nearest and d₂_second

3. Compute ratio: r = dist(d₁, d₂_nearest) / dist(d₁, d₂_second_nearest)

4. If r < 0.7 (selected from Figure 6(b) in paper), add to list of matches (d₁, d₂_nearest)

We assume that good matches should have a clear winner (low 1-NN distance / 2-NN distance ratio) while bad matches have similar distances to multiple candidates (higher ratio)

Part B.4: RANSAC for Robust Homography

In this section I implement RANSAC and create automatic mosaics using the same warping and blending pipeline from Part A. The results demonstrate that 4-point automatic feature detection and matching can produce mosaics comparable to (or better than) manual correspondence selection, while being much faster and more scalable.

RANSAC Algorithm

Repeat for N iterations:

1. Randomly select 4 matches (minimum needed for homography)

2. Compute homography H using these 4 points (exact solution)

3. For each match (p₁, p₂):

• p₁' = H × p₁

• Compute distance ||p₁' - p₂||₂

• If e < threshold, add to inliers list

4. Track H with most inliers

After all iterations:

5. Recompute H using all inliers
