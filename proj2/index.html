Project 2: Fun with Filters and Frequencies

Exploring image processing through convolutions, edge detection, hybrid images, and multiresolution blending

Overview

This project explores fundamental concepts in image processing and computer vision through the implementation of various filters and frequency domain manipulations. We'll build convolution operations from scratch, implement edge detection algorithms, create hybrid images that change perception based on viewing distance, and perform seamless image blending using multiresolution techniques.

Part 1.1: Convolutions from Scratch!

I implemented 2D convolution from scratch using both four nested loops and optimized two loops with numpy operations. The implementation includes proper zero padding to maintain image dimensions. I compared my implementation with scipy.signal.convolve2d to verify correctness.

def convolution_4_loops(img, kernel):
    img_h, img_w = img.shape
    ker_h, ker_w = kernel.shape
    pad_h, pad_w = ker_h // 2, ker_w // 2 # amount of padding to add
    
    # pad the image with zeros on all sides and copy rest of image
    padded = np.zeros((img_h + 2 * pad_h, img_w + 2 * pad_w))
    padded[pad_h:pad_h + img_h, pad_w:pad_w + img_w] = img
    
    output = np.zeros((img_h, img_w))
    
    for i in range(img_h):
        for j in range(img_w):
            for k in range(ker_h):
                for l in range(ker_w):
                    output[i, j] += padded[i + k, j + l] * kernel[k, l]
    
    return output

def convolution_2_loops(img, kernel):
    img_h, img_w = img.shape
    ker_h, ker_w = kernel.shape
    pad_h, pad_w = ker_h // 2, ker_w // 2 # amount of padding to add
    
    # pad the image with zeros on all sides and copy rest of image
    padded = np.zeros((img_h + 2 * pad_h, img_w + 2 * pad_w))
    padded[pad_h:pad_h + img_h, pad_w:pad_w + img_w] = img
    
    output = np.zeros((img_h, img_w))
    
    for i in range(img_h):
        for j in range(img_w):
            output[i, j] = np.sum(padded[i:i + ker_h, j:j + ker_w] * kernel)
    
    return output

Runtime & Boundary Handling Analysis

Runtime Comparison:
  • 4-loop implementation: O(H×W×Kh×Kw) - Very slow for large images (~30-60 seconds for my 400x667 image with 9×9 kernel)
  • 2-loop implementation: ~10x faster due to vectorized inner operations with numpy
  • SciPy implementation: a lot faster due to the scipy class using optimized C code
Boundary Handling:
  • My implementation: Uses zero padding - I adds zeros around the image borders of 2 * kernel size // 2 to maintain output size
  • SciPy mode='same': Uses 'fill' boundary condition with fillvalue=0
  • Comparison: Results are identical
  • Edge effects: Both methods produce similar artifacts at image boundaries due to zero assumptions

Part 1.2: Finite Difference Operator

Using finite difference operators on the cameraman image, I computed partial derivatives and created gradient magnitude images for edge detection. The gradient magnitude is computed as √(Dx² + Dy²) and then binarized using a threshold of 0.22 * maximum magnitude = 0.31 to create clean edge images. I chose this threshold to try to highlight features of the cameraman like his eyes, mouth, and ears as well as the shape of the camera, even though I ended up having to tradeoff some of the background details. After trying multiple values, I found that this was a good balance between noise of the background and focusing on the cameraman features without losing too much.

Verification Results

Method Comparison:
The DoG method produces thicker edges compared to raw finite differences because the Gaussian smoothing spreads edge responses spatially. When we blur the image first, sharp intensity transitions (edges) get smoothed over a wider area determined by the Gaussian kernel size. The subsequent derivative operation then detects these spread-out transitions as thicker edge responses. In contrast, finite differences operate on the original sharp transitions, producing thinner but noisier edges. Because of this thickness trade-off, we sacrifice some edge localization precision to gain significant noise reduction and more robust edge detection.

Part 2.1: Image "Sharpening"

I implemented the unsharp masking technique for image sharpening. The method works by extracting high frequencies (original - blurred) and adding them back to the original image with amplification: Sharpened = Original + α × (Original - Blurred). This can be combined into a single convolution operation using the formula (1 + α)δ - αG.

For the pizza and ladybug hybrid, I used a sigma of 10 on the low frequency and 7 on the high frequency image. Moreover, I put 1.5x more weight on the high frequency image in order to produce this result. The low-pass filter is done by convolving a gaussian kernel like we have done before. The high pass filter subtracts the low-pass filter from the original image, which highlights areas like edges. This is then combined into a weighted average using the alpha values I have defined. The hybrid images work by exploiting the human visual system's frequency response. High frequencies are more visible up close, while low frequencies dominate perception at a distance. Proper alignment of key features (eyes, center objects) is crucial for the effect.

Part 2.3 & 2.4: Multiresolution Blending

Following Burt and Adelson's 1983 paper, I implemented multiresolution blending using Gaussian and Laplacian stacks. Unlike pyramids, stacks maintain the same dimensions across all levels. The algorithm blends images smoothly by combining different frequency bands with progressively blurred masks.

Algorithm Summary

  • Step 1: Build Laplacian stacks for both input images
  • Step 2: Build Gaussian stack for the blending mask
  • Step 3: Combine Laplacian at each level using blurred mask weights: Blend = G×L1 + (1-G)×L2
  • Step 4: Reconstruct final image by summing all combined Laplacian levels

This approach creates seamless blends by smoothly transitioning different frequencies. Low frequencies are at lower levels, high frequencies are at higher levels. High frequencies blend sharply (binary mask), while low frequencies blend smoothly (heavily blurred mask), eliminating visible seams.

Learning Experience

The most important thing I learned from this project is how frequency analysis provides a unified framework for image processing. Whether it's edge detection (high-pass filtering), smoothing (low-pass filtering), hybrid images, or multiresolution blending (frequency-specific combination), all these operations can be understood through the lens of how they manipulate different frequency components of images. This frequency perspective reveals why certain techniques work, how to tune parameters effectively, and how to combine methods for more sophisticated effects. It made me more curious about how many filters applications or editing techniques like Snapchat filters, Photoshop are produced.
